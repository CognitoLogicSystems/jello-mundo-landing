# Jello Mundo — Glass Digital Gold Landing

Genesis Pack rewritten around the **Glass Digital Gold** line. Five skins, one vault, a 10-second hero loop.

## Open

Open `index.html` in a browser. No build step.

## Structure

```
index.html
assets/
  css/style.css
  js/main.js
  stills/          ← five 1280×720 working plates (drop masters here)
  video/           ← hero-loop.mp4
  unused/          ← relic / pug / bulldog, off the page
```

## The five skins

| Unit | Still |
|---|---|
| Vault Lineup | opening row of units |
| Pink Cortex Helm | glass skull, living pink brain |
| Glass Digital Gold | blue bob, gold dust in the chest |
| Shatter Iris | iridescent armor breaking the pane |
| Caged Oracle | red-lit brain, glasses, box |

## Before Gumroad

Drop your final high-res PNGs over the five still filenames. The plates on the page are 1280×720 working frames, not print masters. Checkout stays dark until the masters land.
